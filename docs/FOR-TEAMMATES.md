## 二、队友那边必须先装的东西（这一步不能省）

**这个应用本身不含任何 agent。** 它只是个工作台，把队友**本机已装的** claude / codex / opencode
拉起来干活。队友机器上没有这些 CLI，界面能开、但引擎全是灰的。

队友需要：

1. **Node.js**（因为下面三个适配器都是 npm 全局包）
2. 三条安装命令（在本机实测的版本）：

   ```
   npm i -g @agentclientprotocol/claude-agent-acp     # 本机 0.89.1
   npm i -g @agentclientprotocol/codex-acp            # 本机 2.2.2
   npm i -g opencode-ai                               # 本机 1.17.14
   ```

   注：`opencode` 用 bun 装（`bun add -g opencode-ai`）也行，应用是查 PATH 的，不挑安装方式。

3. **各自的账号凭据**（这步最容易被漏）：
   - claude 系：`%USERPROFILE%\.claude\settings.json` 里的 `env`（就是 CC Switch 写的那份）
   - codex 系：`%USERPROFILE%\.codex\config.toml` 的 custom provider

   换句话说：**队友得先能在他自己的命令行里把 claude / codex 跑起来，这个应用才能用它们。**

装完可以对一下：`where codex-acp` / `where claude-agent-acp` / `where opencode` 各自要有输出。

## 三、队友第一次打开会看到什么

1. **Windows 会弹「已保护你的电脑」**——因为我们没买代码签名证书。点「更多信息」→「仍要运行」。
   这是预期行为，不是文件坏了。企业管控比较严的机器可能直接拦掉，那种情况得走内部分发。
2. 首屏有个**首次启动引导**浮层，写清了：哪些引擎会产生审批、什么动作会打断你、数据在哪、
   一行怎么开始。点「知道了」就不再出现。
3. 左栏是**引擎列表**（本机装了哪几家），每行一个「+」，点它就直接起一个该 agent 的会话。
   灰显的就是没装，旁边写着该敲哪条命令。
4. 数据全部写在 `%APPDATA%\bumimang\`（workspace + evidence），删掉这个目录等于清空状态。

## 四、如果队友的 CLI 装在奇怪的地方（PATH 里没有）

应用查不到就会灰显。兜底办法是按架构文档 §6.1 写一个显式路径表：

`%APPDATA%\不迷茫\agents.json`（**注意这个目录名是「不迷茫」，跟应用数据目录 `bumimang` 不是一个**，
这是历史遗留的命名不一致，容易踩）：

```json
{ "opencode": "C:\\完整\\路径\\opencode.exe", "codex": "...", "claude": "..." }
```

> 诚实标注：这条兜底路径**我们没实跑过**（要往仓库外的 AppData 写文件，属于需要你授权的操作）。
> 代码里读的就是这个路径，但「写进去真的生效」这件事只有代码可读、没有运行证据。

## 五、还没验过的（别对队友说满了）

1. **没在干净机器上装过**。这台机器有 Node 全局包、有 electron 缓存、有三家的登录态，
   所以"在本机能跑"**证明不了**"队友机器开箱可用"——缺什么依赖恰恰是没验的那部分。
   要真验，得在一台干净的 Windows 或虚拟机上走一遍。
2. **没有代码签名**，SmartScreen 一定报警告。
3. **NSIS 安装包没执行过**（B-4），所以只发绿色版。
4. 卸载：绿色版没有卸载器，关掉窗口、删掉那个 exe 就行；残留只有 `%APPDATA%\bumimang\`。

> 发你一个 Windows 上的多 agent 工作台（不迷茫）。双击 `不迷茫 0.1.0.exe` 就能跑，不用安装、

>
> 数据写在 `%APPDATA%\bumimang\`，不想要了把这个目录删掉即可。
>
> 文件校验：SHA256 `C40246B780940D558FC37F04130005AE9F408A13CC4BA7F685703D1572AF9268`。
