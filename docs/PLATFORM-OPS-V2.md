# 不迷茫 · 比赛平台多 Agent 作战版（2026-11-01）

## 本轮改动

1. **平台题目完整同步**
   - `NestClient` 增加分页兜底：服务端返回 `total > 当前页` 时继续拉取，
     直到取完或服务端明确停止翻页。
   - UI 始终显示“平台标注 X / 当前可见 Y”；账号无权限或未解锁的题不会被
     伪造为可打开题目。

2. **12 Agent 自动编队**
   - 单题仍最多 4 个 Agent；全局最多 12 个。
   - “一键抢旗”会按分值/解出数顺序填满最多 3 道未解题。
   - 自动接力只补空闲槽位，不重复启动同一题已有的 Agent。

3. **现场健康探测与止损**
   - 每 30 秒对运行中题目的 HTTP/TCP 靶机做一次只读探测。
   - HTTP 5xx、TCP 断连显示为靶机异常。
   - 异常持续 4 分钟：停止该题会话、冷却 10 分钟、自动换下一题。
   - 开靶 5 分钟仍无地址：冷却 30 分钟，不占全局配额空转。

4. **停滞纠偏**
   - 空闲会话 2 分钟最多唤醒一次。
   - 工具调用连续 6 分钟不增长的运行会话，收到“停止空想、读黑板、做最小验证、
     写 dead_end 或输出 flag”的纠偏提示。

5. **Flag 自动提交与纠错**
   - 识别标准 flag 候选后自动调用平台提交适配器。
   - 平台明确拒绝：候选标为 `false_positive`，把平台反馈回灌给全部活跃 Agent，
     要求换证据/换路径，禁止重复提交同值。
   - 网络超时、登录失效、平台 5xx：候选保留为 `new`，提交状态标为 `timeout`，
     10/20 秒自动重试两次，不把临时故障误判成错误 flag。
   - 平台接受：任务 `solved`，候选 `confirmed + ok`，自动停止该题剩余会话。

6. **低延迟与界面**
   - 关闭 Electron 后台 timer/renderer/occluded window throttling。
   - 开靶等待从 20 秒降为 8 秒；地址未下发时先启动 Agent 做离线分析，
     后台继续轮询并注入地址。
   - Flag 区上移到题目详情首屏；平台说明移到题卡上方。
   - 新增靶机 200/5xx/断连徽标、“已暂停/解题中”真实状态、全局 Agent 配额、
     活跃题数与靶机 UP/DOWN 状态条。

7. **大附件**
   - 平台题目导入上限提高到 2 GiB / 5000 文件，适配大型镜像取证题；
     手动上传默认仍保持较保守的 200 MiB。

- 3 道题 × 4 Agent = 12 个并发会话。
- 平台题目接口实测返回 21 道可访问题；账号无权访问的其余题目不会伪造。
- 靶机探测实测：`Handoff` TCP 97ms 正常，`Pending Review` HTTP 502 判为异常。
- 新版隔离实例启动成功，控制台无未捕获异常；renderer heartbeat 5 秒稳定，
  无后台节流告警。

  `submit_status=ok`，平台同步为已完成。

- 回归：`verify:all`、`smoke`、`verify:flags` 全部通过。
