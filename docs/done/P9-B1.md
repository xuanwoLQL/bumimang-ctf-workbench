# P9-B1 · AWD 只读 UI

> 状态：**P9-B1 完成**。日期：2026-10-25。
> 范围：renderer 只读 AWD 面板（轮次/服务/flag 轮换/补丁/检查/攻击/告警）；**不新增 Hub action、不做写操作/平台 API/自动动作**。
> 依据：`docs/plans/WP9-plan.md` §4、`docs/done/P9-A.md`。

## 做了什么

- 新增 `apps/desktop/src/renderer/awd/panel.ts`：
  - `awdVisible(state)`：仅 `task.category=awd` 且 `state.awd` 存在时显示。
  - `buildAwdPanelModel(view)`：纯视图模型（轮次文本/服务/flag/补丁/检查/攻击/warnings）。
  - `formatAwdRemaining(round)`：运行中显示 `剩余 MM:SS`；结束显示「已结束」；无轮次「未开始轮次」。
  - `createAwdPanel(host, ctx)`：右栏 `AWD（只读）` 面板；store 订阅 + 1s 只刷新倒计时文本。
- `store.ts`：`AppState` 新增 `awd/ir`（P9-A 视图）；`applySnapshot` 复制 `snap.awd/ir`；`emptyState`/`clearFocus` 置 null。
- `contract.ts`：再导出 `AwdView`/`IrView`。
- `main.ts`：挂载 `createAwdPanel(right, ctx)`。
- `styles.css`：AWD 面板只读样式（右侧竖线、行分隔、tabular 倒计时）。
- `smoke.ts`：4 条纯模型/可见性断言（716 total）。

## 行为

- category=awd 的焦点任务显示 AWD 面板；其他任务/旧快照隐藏。
- 只读展示：
  - 轮次：第 N 轮/状态/剩余时间（1s 更新文本，不发 action）。
  - 服务：name/target/status/负责人/补丁状态。
  - flag 轮换：round/value/status/evidence/已提交。
  - 补丁：service/vuln/status/evidence/witness。
  - 防守检查：round/item/status/evidence。
  - 攻击日志：attacker→target/action/result/evidence。
  - `warnings`：结构化 fact 解析告警。
- **没有按钮/写操作**：开始/结束轮次、补丁/检查/攻击写入需要后续 Hub action 或现有黑板路径；本步不新增契约。
- 不自动扫描/利用/开环境；不接平台。

## 已知限制

1. 只读：没有开始/结束轮次、服务状态、补丁/检查/攻击的编辑入口；这些需要后续 Hub action/黑板写入契约（本步不新增）。
2. 没有 AWD 专用 mock 世界；mock 需注入 `awd` 快照/真实 category=awd 任务才显示。
3. 面板 DOM 只做纯模型断言 + Electron 加载；没有自动 DOM 可见性断言（`awdVisible` 已单测）。
4. 轮次倒计时按本机时钟；不自动同步平台轮次。
5. 服务状态复用 `TargetStatus`（unknown/alive/owned）；fact `down` 映射 unknown。
6. 未映射 flag 归 round=0，UI 显示「第 0 轮」；需要人工区分。
7. 附件/工件不在 AWD 面板；IR 面板留 P9-B2。
8. 无导出/批量提交（P9-C）；无强类型表（P9-D）。
9. 无真实 AWD 数据；UI 未经过真实比赛流程评审。
10. 右栏面板较多；AWD 面板位于右栏底部，小屏幕可能需要滚动。
11. 不接平台 API/不自动提交/利用/开环境。
12. 不自动重建整栏（仅 1s 倒计时文本），store 变化才重建面板。
