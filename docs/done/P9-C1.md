# P9-C1 · AWD/IR 导出契约 + 只读导出

> 状态：**P9-C1 完成**。日期：2026-10-25。
> 范围：新增可选 `awd.export`/`ir.export` 契约 + 纯导出 md/csv/json + Hub action/审计 + AWD/IR 面板导出按钮。
> **不写文件、不接平台、不自动提交；批量 manual 提交留 P9-C2。**

## 做了什么

### 1. 契约

`packages/shared-protocol/events.ts`：

```ts
| { type: "awd.export"; taskId?: string; format: "md" | "csv" | "json" }
| { type: "ir.export"; taskId?: string; format: "md" | "csv" | "json" }
```

- `taskId` 缺省 = 当前焦点任务；返回 `ActionResult.content`；不写文件。
- `validate-action.ts` 新增两 action 的白名单/format/taskId 校验。

### 2. 纯导出

新增 `apps/desktop/src/main/awdir/export.ts`：

- `exportAwd(view, format, now?)` / `exportIr(view, format, now?)`。
- md：分节表格（AWD 轮次/服务/flag/补丁/检查/攻击；IR 证据板/时间线/问题/告警）。
- csv：扁平表头 + 行；引号/逗号/换行转义。
- json：`format/exportedAt/taskId/...` 可解析。
- 纯函数；无 fs/网络/平台。

### 3. Hub

`hub.ts`：

- `awdViewForTask(taskId)` / `irViewForTask(taskId)`：按 taskId 构造只读视图（导出不依赖焦点）。
- `awd.export`/`ir.export`：format 校验、taskId/归档/category 校验、返回 content。
- 审计只记 `taskId/format/count`，**不记 content/flag 明文**；不写 events。
- 无平台 API/自动提交。

### 4. UI

- AWD/IR 面板新增 `导出：md/csv/json` 按钮；点击 dispatch 对应 action，拿 `content` 弹现有只读导出 modal（复制/关闭，不写文件）。
- `flags.ts` 的 `openExportModal` 改为可复用（title/note 参数；默认 flag 文案不变）。
- 仍无写事实/轮次/补丁按钮；只读视图 + 只读导出。

## 行为变更

- 焦点/显式 taskId 的 AWD/IR 任务可只读导出 md/csv/json；内容返回、不写文件。
- AWD/IR 面板出现导出按钮；导出失败可读提示；成功弹复制 modal。
- 导出审计只记 format/count，不记内容/flag 明文。
- 非 AWD/IR 任务、归档任务、非法 format 被拒绝。
- 无平台 API/自动提交/自动利用/开环境。

## 已知限制

1. **P9-C2 未做**：AWD 批量 manual 提交编排（勾选/一次确认/逐条 flag.submit）尚未实现。
2. 导出内容含 flag 明文/敏感路径；由用户复制保存，不写文件。
3. 导出审计不记 content；无法从 audit 还原导出内容（有意）。
4. IR 导出不做固定问题模板/平台格式（用户决定）。
5. AWD/IR 面板导出按钮只做代码/Electron 加载；无 DOM 按钮自动断言（`verify:awdir` 测纯导出/action）。
6. 导出 json 含完整视图（含 warnings/attachment/artifact），体积随数据增长；未分页。
7. CSV 是扁平表；不同实体列语义不完全一致，适合人读/表格导入，不适合严格 schema。
8. 无平台 API/批量提交/自动利用。
9. 无真实 AWD/IR 数据；导出格式未经真实比赛流程评审。
10. `awd.export`/`ir.export` 为可选动作；旧渲染层不调用不炸。
