## 一、冷启动我（新手）实际看到的、以及我卡在哪

窗口打开，三栏，一片暗色。没有任何标题、引导，说清「这是什么、三栏分别是干嘛的」。

1. **左栏**：一个小徽标「规则包 policy-engine(比赛合规包)」——**我不懂「规则包」是什么，也不知道这代表「闸门到底武装了没有」**。
2. **任务卡片**：标题「示例任务：本地 HTML 目标」，状态写着 **「状态：open」**——中文界面里漏一个英文枚举，而且**我明明没建过任务，哪来的示例任务？这就是我要打的靶吗？** 没人告诉我。
3. **会话区**：「还没有会话」+「点下方 + 扇出起第一个会话」——这是唯一指路的，还好。
4. **中栏（最大的一块）完全空白**——第一反应：**界面没加载完 / 坏了**。没有任何「这里以后会出现什么」的说明。
5. **右栏审批**：「待审批 0 条 / 暂无待审批」，下面很密的一段「空有两种可能 ①②…」。内容其实诚实，但**我不懂「审批」是干嘛的、为什么我需要关心它**。
6. **右栏黑板**：「黑板为空」+ 事实/死路/意图/租约四个「暂无X」——**「黑板」「事实」「死路」「租约」全是黑话**，没人解释。

然后我点唯一的蓝色按钮「+ 扇出会话」。

7. **弹窗**：agent 下拉有 4 家（OpenCode/Codex/Claude Code 可用，DeepSeek Harness 灰显）。**我不知道选哪个 agent 有什么区别**——下面写的「成熟度」全是「ACP 原生子命令 / 官方适配器已安装」这类**对我选 agent 毫无帮助**的信息。真正重要的区别是：**哪些 agent 会在动手前先问我（进审批队列），哪些会闷头干**——这个信息当时完全没有。
8. **档位**：guarded·受控（逐条审批）/ autonomous·自主（只拦硬阻断）——有解释，但**「硬阻断」还是黑话**，而且没告诉我：guarded 的「逐条审批」只有在 agent 真的会请求授权时才成立。
9. 我随便选了 OpenCode（默认第一个可用），点「扇出」→ **弹窗关了，然后……什么都没发生**。spawn 一个 agent 要几秒到几十秒，这段时间我看到的只有「我点了，然后没反应」。如果它失败了（agent 没装 / 启动失败），**我永远看不到任何报错**——派发结果被代码直接丢掉了。
10. 会话起来后，中栏出现一个窗格：头部「opencode lead 受控 运行中 **同步 N/A**」。**「同步 N/A」是什么意思？** body 一片空白——**如果这个 agent 一直不产出任何东西，窗格就永远空着**，只有等到 30 秒后且满足特定条件才有一条灰色小字（而且那条只解释「没审批/没读黑板」，不解释「没输出」）。

## 三、修了什么（每条对应一个困惑）

都在我的 lane（`apps/desktop/src/renderer` + `apps/desktop/electron`），**没有动契约、没有动 src/main**。

1. **C1 → 中栏空状态**（`panes.ts` + `styles.css`）：没有会话时中栏渲染一块虚线说明「还没有会话窗格 + 点左栏扇出，每个会话会占一个窗格实时滚动动作流」。新手第一眼不再看到一片空白。
2. **C2 → 扇出反馈 + 失败可见**（`fanout.ts` + 新增 `notice.ts` + `styles.css`）：点「扇出」立刻弹一条「正在启动会话…（首次启动可能需几秒到几十秒）」的瞬态提示，再关窗；`dispatch` 失败时把 `{ok:false, error}` 弹成红色提示条。「一键扇出」失败时列出「失败 N/3：…」。
3. **C3 → 窗格无输出占位**（`panes.ts`）：每个窗格 body 先有一句「会话启动后动作流会实时滚到这里；目前还没有输出」，有事件流进来就移除；终态（blocked/done/failed/stopped）且无输出时改成「该会话没有产生任何输出」。健康度加 `title` 工具条解释「同步滞后 / 工具调用数」。
4. **C4 → 闸门武装绿标**（`main.ts` + `styles.css`）：真实规则包在跑（未回落）时，规则包徽标加一个绿色「已武装」小标；回落最小安全集时维持黄字「已回落最小安全集」。一眼回答「武装了没有」。
5. **C5 → 选 agent 行为提示**（`fanout/model.ts` + `fanout.ts`）：弹窗里加一条「guarded 档取决于 agent 会不会主动请求授权——当前只有 Claude Code 开箱会问，OpenCode/Codex 默认不问」；选中 agent 时把「默认会不会请求授权」并进成熟度一行。数据源是渲染层过渡常量 `AGENT_GATE_NOTE`（真正的家是 detect.ts，见 BLOCKED R-2）。
6. **C6 → 任务状态中文化**（`session-status.ts` + `main.ts`）：`状态：open` → `状态：待解`（open/solving/solved/abandoned → 待解/解题中/已解出/已放弃）。

> C8 说明：左侧卡/窗格的 lead/guarded 原始值我**故意没动**——窗格头的角色徽标被 real-parallel-verify 断言成原始值，改中文化会破坏已验收证据；而且扇出弹窗选的时候已经教过「lead·主攻」等含义，属于低优先级的一致性瑕疵，记在这里以免后人当 bug 再查一遍。
