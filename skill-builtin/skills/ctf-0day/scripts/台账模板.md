# 台账模板（复制到工作目录用）

> **为什么必须有**：长赛事最大的隐性损耗是重复劳动；AI 会话还会被上下文压缩。
> 把"已消除的假设 / 已拿到的凭据 / 已提交的 flag / 当前入口"落到文件里，压缩后还能续。
> 完整判据见 `知识库/破局模型.md` 第 1 步。
>

---

## 1. 假设台账（每台目标一张）

| 目标 | 已确认事实 | 已消除的假设 | 存活假设（按可能性排） | 下一步 | 卡点 |
|---|---|---|---|---|---|
| 10.0.0.11:8080 | 指纹 Jenkins 2.4xx；`/script` 403 | 无鉴权 `/script`；CLI 端口（8080 外未开） | ① 弱口令 ② CVE-2024-23897 文件读 ③ 凭据解密链 | 跑弱口令字典 | — |
|  |  |  |  |  |  |

**用法要点**

- **"已消除的假设"是核心**——防止你把同一个想法试第二遍。
- 有新事实就加一行。**台账不再增长 = 卡死信号**（换线判据，不看表）。
- 换线时后台任务不要杀，在"下一步"里记下"后台还在跑什么"。

## 2. 收口三行（每台机器打完）

```
IP | 入口洞 | flag/权限 | 卡点 | 下一步
10.0.0.11 | Jenkins /script 弱口令 | flag{...} / www-data | 提权未果 | 试 CVE-2024-23897
```

## 3. flag 台账

| flag 值 | 来自（机器 / 位置） | 是否已报告 | 时间 |
|---|---|---|---|
| `flag{...}` | 10.0.0.11 `/flag` | ✅ 通过 | 14:22 |
| `flag{...}` | 10.0.0.11 数据库 flag 表 | ⏳ 未提交 |  |
|  |  |  |  |

**纪律**：flag 到手**立刻报告**（提交归人工）；记下"已报告"的时间以备 flag 轮换重拿。

## 4. 凭据台账（横向的种子）

| 来源机器 | 账号 | 口令 / hash | 类型 | 已试过哪些目标 |
|---|---|---|---|---|
| 10.0.0.11 | root | `P@ssw0rd` | 明文 | 10.0.0.12:22 ✗ / 10.0.0.13:3306 ✗ |
|  |  |  |  |  |

**纪律**：拿到任一套凭据，**立刻全段复用**（比赛密码复用率极高，这是内网最大分差来源）。
