# 知识库索引

CTF / 决赛靶场技能的知识库。与 `SKILL.md` 路由表配合使用。

## 使用约定

- **开局先看 `打穿短表.md` 一份**，对得上再打开对应模块。禁止每台靶机通读本目录。
- **按层加载，别预读**：`SKILL.md` → `打穿短表.md`（起手 + 症状索引）→ 命中的分类篇 → 篇内**先读顶部「目录」再定点开节**。
- **超过 300 行的篇已统一加「目录」**——长文不要线性通读，先看目录定位那一节。
- **分线加载**：渗透题只读渗透侧，应急题只读应急侧，双线赛制两边全开。
- Web 应用层手法在 `web/` 子库（49 文件）；该子库语料源自 SRC 语境，「安全红线 / 最小伤害 / 禁批量 / 只证不 dump / 报告定级」在靶场**一律不适用**，只取手法。详见 `web/README.md` 顶部。
- **外源按需加载**：先查核心库；无命中，或题目明显属于经典 Web / Misc / Crypto / 历史大赛同型题时，才看 `Des-CTF外源索引.md`，并用 `kb_search(..., source="des")` 定点检索。禁止整批通读 1027 篇索引。
- 短表不是上限：现场有什么打什么。卡住时回 `破局模型.md`。

## 边界

- **ctf-0day（不迷茫）**：授权比赛靶机专用——批量 / dump / 写操作全放开，目标就是打穿拿分。**自包含**，不依赖本机其它技能。
- 线上真实资产（SRC 挖洞、白盒审计）不归本技能；混用时认语境，说「靶场」「CTF」「flag」「决赛」「应急」走本技能。
