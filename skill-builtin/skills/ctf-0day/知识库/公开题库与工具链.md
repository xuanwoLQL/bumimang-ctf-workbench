### ★ 内网与客户端：真正缺的工具（2026-10-10 全盘实测）

> **核实方式**：跨 `C:\tools` / `Downloads` / `_tools` / WSL 全盘找，并**区分"真工具"与"只是 nuclei 模板"**
> （例如 `mimikatz` 只找到 `impacket-src\examples\mimikatz.py`（impacket 封装，非原生 mimikatz）；
>  `antsword` 只找到检测模板 `antsword-backdoor.yaml`）。

| 工具 | 状态 | 缺了会怎样 | 补齐方式 |
|---|---|---|---|
| **chisel** | ❌ **全盘无** | **没有隧道 = 内网进不去**（最高优先级） | 单文件二进制，直接下 |
| **frp** | ❌ 无（只有 nuclei 模板） | 同上（长连/多端口转发更顺手） | 单文件 |
| **ligolo** | ❌ 无 | 缺"工具不走代理也能用"的 TUN 方案 | 单文件 |
| **proxychains** | ❌ **WSL 也没有** | 代理链下跑工具不便（`nmap -sT` 等要手动配） | `apt install proxychains4` |
| **mimikatz** | ⚠️ 仅 impacket 封装 | **原生抓凭据/PTT 用不了**；可用 `secretsdump.py` 部分替代 | 单文件（Windows 侧执行） |
| **procdump** | ❌ 无 | lsass 转储的免杀替代缺失 | 单文件 |
| **蚁剑 / webshell 客户端** | ❌ 无 | **"连马"环节缺工具**（题目流程常要求） | 平台内置工具库，或现成客户端 |

**★ 一条命令补齐前三项（最影响内网的）**：
```bash
# WSL 里装 proxychains（其余三个是单文件二进制，下到 C:\tools\bin 即可）
wsl -d ghost -- sudo apt-get install -y proxychains4
```
