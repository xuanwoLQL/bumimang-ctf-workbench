# 打穿短表（开局侦察 + 高频手法索引）

> 开局先看本表：§开局侦察 是起手命令块，下面是手法索引；对得上再打开「见 xxx.md」看细节。禁止每台靶机通读整库。
> **本表 ≠ 完整清单。** 表上没有的手法照样打；打点细节认 `中间件漏洞.md`，Web 通用漏洞认 `web/` 子库（红线条款不适用，只取手法）。
> 靶场哲学与 SRC 相反：**批量放开、dump 放开、写操作放开**。flag = 分，权限 = 分，速度 = 分。
>
> **起手顺序按消除率排**（`SKILL.md` §一）：手上已有的先试 → 一键工具 → **搜现成 PoC** → 读信号 → 手工推演。
> 第 3 步被跳过是最贵的失误。卡住时不要加大尝试量，回 `破局模型.md` 榨信息 / 跑组合矩阵。

## 开局四问（90 秒，先过这一关再动手）

> 依据：历次实战里代价最大的失误全在这四问 —— **跳过它们直接试手法，是白干一整轮的最常见原因**。

| # | 问 | 命中就怎么办 |
|---|---|---|
| 1 | **有没有分？** | `has_flag=0` / 平台未登记 flag ⇒ 降级为技术练习，不投入时间。**实测判据**：提交接口会直接回 `{"success":false,"message":"此靶场没有flag"}`（249 实测）—— 这**不是卡住，是没分**，立刻止盈换题 |
| 2 | **靶机活着吗？** | `curl` 十连发探稳；Java 重型环境（WebLogic / Spring Cloud）2–7 分钟仍 000 ⇒ **5 分钟不可达即弃** |
| 3 | **回连通道成立吗？** | 要靶机回连的链（JNDI 反连 / Evil MySQL / 反弹 shell / OOB）**先测通道**；只放 HTTP 出网 ⇒ 改走 HTTP/DNS 外带或公网 paste 托管 |
| 4 | **有没有历史记录？** | 平台记录 / 别人的 writeup / 题目备注先看；答错多次的题先看记录再动手 |

> 然后：**读题面 30 秒**（题名 / 提示 / 源码注释常直接写着解）→ **侦察 3 分钟** → **去 `题型图鉴.md` 对号**，对上哪一类就套哪一类的打法。
> 打完立即 **交 flag**（与当前实例强绑定，见 `题型图鉴.md` §26.4）。

## 开局侦察（起手三分钟）

> 比赛开局五分钟决定节奏：**扫描后台跑，人看 Web**。禁止干等工具（赛制与时间刻度见 `比赛节奏与赛制.md`）。
> 打点台账边打边落：`IP:端口 | 服务/指纹 | 试过什么 | 通/不通 | 卡点 | 下一步`——比赛 4 小时没有台账 = 重复劳动。
> 工具按**全路径**调最稳（`fscan`、`jadx`、`java` 都不在 PATH，见 `SKILL.md` §八）。

### 端口与服务

```bash
# 全端口必扫（比赛洞常在冷门端口）
nmap -sT -Pn -p- --min-rate 5000 10.10.1.11 -oA all
nmap -sV -sC -p 80,443,8080,7001,8848,6379,3306,8161,9999 <开出来的端口> -oA svc

# fscan 一把梭（存活+弱口令+POC，内网首选）
C:\tools\bin\fscan.exe -h 10.10.1.0/24 -o result.txt

# UDP 顺手一眼（SNMP 161 常漏）
nmap -sU --top-ports 50 10.10.1.11
```

- 只扫 top1000 端口 = 主动漏分。`-p-` 全端口是纪律
- fscan 结果存档：端口表+弱口令+漏洞三列，作为打点台账，边打边更新

### Web 指纹

```bash
whatweb http://IP:PORT
# 手工：报错页、响应头（X-Powered-By/Server）、favicon hash、登录页样式、cookie 键名（JSESSIONID=Java、PHPSESSID=PHP、rememberMe=Shiro）
```

指纹 → `中间件漏洞.md` 对应节。认不准时：目录扫描先跑。

**★ 前端加密 = 白给（登录类题的高频障碍）**：登录包是密文时，先读 `encrypt.js` 一类的前端逻辑（找 AES key/IV、自定义字典、Base32 表），用 Python 本地复刻后**照常爆破**。
> 实测：两道题的密文登录分别用 AES-CBC 与 Base32 字典实现，复刻后与明文爆破无差别。**别在"密文看不懂"上停住。**

**IP 头矩阵（来源校验类题的通用弹药 —— 每道题只认一个头，脚本一次全试）**：

```
X-Forwarded-For  →  X-Real-IP  →  X-Client-IP  →  True-Client-IP
X-Cluster-Client-IP  →  CF-Connecting-IP  →  Proxy-Client-IP / WL-Proxy-Client-IP
Cdn-Src-Ip  →  Ali-CDN-Real-IP  →  Fastly-Client-IP  →  X-Originating-IP
X-Remote-IP  →  X-Remote-Addr  →  X-Original-URL / X-Rewrite-URL（路由类）
```

- 拿不到结果别只加大力度 —— **换头名、换大小写、换下划线（`X-Forwarded-For` vs `X_Forwarded_For`）、放 query / POST body**。
- 一次写个循环把矩阵全打一遍，比手试快一个量级。

### 目录与文件

```bash
# 目录扫描：本机没有 dirsearch，用 ffuf / gobuster（都在 PATH）
ffuf -u http://IP/FUZZ -w C:\tools\wordlists\common.txt -e .php,.jsp,.html,.zip,.bak -t 30
gobuster dir -u http://IP -w C:\tools\wordlists\common.txt -x php,jsp,html,zip,bak -t 30
# 字典本机实况：C:\tools\wordlists\（common.txt/top20/top30，目录扫够用）；更全的走 SecLists Discovery/Web-Content
# ★ 官方字典（登录爆破与用户名枚举先交叉这三份，命中率高于通用字典）：
#   github.com/haobachang-1/haobachangBlog/tree/main/dict  →  Password.txt + chinaname.txt + common_phones.txt
#   raw.githubusercontent.com 断连时走 cdn.jsdelivr.net/gh/<owner>/<repo>@main/dict/<file>
# Java 站字典换成 jsp,do,action；重点路径手工补：
/admin /manager /console /actuator /druid /swagger-ui.html /nacos /xxl-job-admin
/.git /.svn /robots.txt /WEB-INF/web.xml /phpinfo.php
www.zip 域名.zip backup.zip wwwroot.rar 1.zip
```

- `.git` 泄露 → GitHack/dvcs-ripper 恢复源码（源码 = 配置里的凭据 + 0day 现场）
- `WEB-INF/web.xml` 直接读 → 拿 class 路径下反编译找注入
- Swagger 暴露 → 接口清单里专挑 admin 类无鉴权口

### 流量与旁路

- 开局挂 Wireshark/流量镜像（AWD 必须）：别人打出来的 payload 直接抄来反打
- 有域名绑定环境 → 子域枚举（比赛少见但碰到就是新面）
- CDN/WAF 判定：wafw00f 或发 `'` 看拦截页 → WAF 拦了开 `web/waf-bypass.md`（手法照用）

### 侦察假点

- **薄容器（Flask/Werkzeug dev server 类单线程靶机）目录扫必须 `-t 1~2`**：`-t 20` 一轮就把容器打崩（端口变 closed），且多数 CTF 平台无看门狗不会自动重启，只能让用户手动重开环境、损失全部现场（2026-09 好靶场 hbc 实测：20 并发 ffuf 直接打死，10 分钟+ 不恢复）。扫描前先 `curl` 十连发探稳，不稳就降到串行
- **容器已经死了怎么续（进程级生命周期）**：连接被拒（`10061`）/ 端口只剩 TimeWait ⇒ 别以为题没了，先定位新实例：
  ```powershell
  Get-NetTCPConnection -State Listen | Where-Object LocalPort -gt 8000   # 看还有哪些端口在听
  Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Select ProcessId,CommandLine
  ```
  **靶机搬迁后必须重跑一次全量入口侦察**（场景数、入口列表、判分方式都可能变），旧结论一律不复用 —— 实测：搬迁后场景从 6 变 9、首页链接也没列全，照旧结论打会漏题。
- 服务版本扫出来是"安全版本"→ 中间件洞照样试（比赛镜像常是魔改/装老组件）
- nmap 全端口慢 → `--min-rate 5000` + `-Pn`，或先 fscan 后 nmap 补细节
- 目录扫 404 全通 → 检查是否泛解析（返回 200 但全是同一页），用响应长度分组判
- 只盯着 80/443 → 8848(Nacos)、7001(WebLogic)、8161(ActiveMQ)、6379(Redis)、9999(XXL-Job executor)、7002、9090、15672 这些端口在比赛里出分最高（XXL-Job admin 在 8080 或独立端口，认 `/xxl-job-admin` 路径别认端口）

## 手法索引

| 认什么 | 打哪 | 出什么算成 | 假点 |
|--------|------|------------|------|
| 开局拿到一段 IP（如 10.10.1.0/24） | `C:\tools\bin\fscan.exe -h 段` 全端口（或 nmap -sV -p-），后台跑；同时人工看已知 Web 端口首页指纹 | 存活清单 + 服务指纹 + 弱口令/漏洞报告（fscan 自带打一轮） | 只扫 80/8080 常见端口漏服务；fscan 报的洞全失败不代表机器没洞，手工接着打 |
| Web 站首页，不知道是什么系统 | 看报错页/响应头/favicon hash/登录页样式；`whatweb`；目录扫 `ffuf -u http://IP/FUZZ -w 字典` 先出 `robots.txt`、`/admin`、备份 | 指纹落到 `中间件漏洞.md` 某一节，开打 | 目录扫全 404 → 试备份文件名（www.zip/域名.zip/.rar/.bak）和 `.git`；指纹认错系统 → 看响应头细节再认一遍 |
| 认出框架/系统（任何） | **先查弹药再手测**（国赛真题教训）：知识库 `中间件漏洞.md` 对应节 → nuclei 指定模板 / 本地武器库（有则用）→ **网搜「指纹 + PoC/CVE」（SKILL.md §情报线，新 CVE 最快路径）**；jeecg-boot、GeoServer、若依这类国产/热门系统基本都有现成弹 | shell | 逐个 API 猜未授权是最慢路径，弹药三连全空了才回手工 |
| debug 模式页面（Django DEBUG 页、Tomcat 报错、Swagger、druid） | debug 页直接翻：**设置/配置节有数据库密码、SECRET_KEY、API token**；Django debug 点「Toggle context」看 settings 全量（磐石真题入口：debug 页拿哈希爆破→SSH） | 凭据/token 到手，直通后台或 SSH | 只看栈不看变量区 → debug 页值钱的是 context/settings，不是报错本身 |
| 请求要 X-Forwarded-For: 127.0.0.1 / 只许本机访问 | 加 `X-Forwarded-For: 127.0.0.1`（或 `X-Real-IP`/`X-Original-URL`）再打；配合参数 Base64 解码后塞 `../../`（磐石真题：XFF+Base64 穿越读任意文件） | 越过来源校验读到文件/进后台 | 只加了 XFF 没动参数编码 → 参数解码后才是文件名，两层都要改 |
