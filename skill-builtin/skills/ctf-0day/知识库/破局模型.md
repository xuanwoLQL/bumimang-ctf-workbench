# 破局模型（压轴题 / 多环链 / 打不动时才开）

> 触发：指纹认不出、短表一条对不上、或一条线跑完仍无战果。
> **另加一条触发（2026-10 补）**：**题目里出现你完全没见过的术语 / 参数名 / 算法构造，且搜索引擎找不到现成 POC** ⇒ 直接从本文件**第 0 步的「★论文题」**看起 —— 那是"论文改编题"的专用入口。
> **难题不是"知识没学到"，是"信息没摆全 + 事实没连起来"。**线下赛的洞几乎都在公开知识里，解出的人只是把信息摆得更全、连得更远、或在判错时没误判成"此路不通"。
> （例外正是论文题：它的答案**不在公开知识库里，只在那篇论文里** —— 所以处理方式不同。）

---

## 第 0 步：先判题属于哪一类（决定用哪套打法）

**先分类，再动手。**三类题的解法完全不同，用错打法就是白烧时间：

| 类型 | 识别特征 | 该干什么 | 千万别 |
|---|---|---|---|
| **知识题** | 指纹 / 版本 / 组件名明确，考的是"这个 CVE / 漏洞你知道不知道" | **搜现成 PoC 直接打**（`SKILL.md` §情报线）；已在 `中间件漏洞.md` 有词条的，连自带武器直接用 | 手搓 API、逐个猜参数——这是最贵的失误 |
| **观察题** | 指纹模糊、页面功能少、报错也说不出所以然，但目标明显有东西没被看到 | **把观察面榨干**（下面第 2 步清单）。JS 全量、备份文件、隐藏路由、注释、时间戳 | 在信号不足时硬发 payload（低消除率，纯烧时间） |
| **组合题** | 已拿到一些碎片（一个凭据、一个文件读、一个 SSRF、一台低权），但都没直接出 flag | **跑组合矩阵**（第 3 步），每个新碎片都回炉重跑一次 | 拿到碎片就以为卡死了 |
| **★论文题** | 题目给的**术语 / 参数名 / API 名你没见过**；或要"复现某方法"；或样本里有**自创算法/协议/魔数**；**搜索引擎搜不到现成 POC** | **先别动手**：从题面线索反查那篇论文（见 §论文题专章），**照论文的公式/参数表/伪代码实现**，而不是猜 | 当"知识题"去搜 PoC（搜不到就以为无解）；当"观察题"去榨界面（论文题的答案不在界面上） |

> **判断依据**：**能不能说清"我要打的这个洞叫什么"。**说得清 = 知识题（去搜）；说不清但感觉有料 = 观察题（去榨）；手里有一堆碎片 = 组合题（去连）；
> **题目里的名词/算法我完全没见过、且搜不到 POC = 论文题（去查文献）**。
>
> **论文题的独特之处（也是它最坑的地方）**：常规题的知识都在公开知识库里，而论文题的答案**只在那篇论文里** ——
> 所以遇到它时，"换 payload 试试"和"再扫一遍目录"都是零收益，**唯一有效动作是找到那篇论文**。
>
> **一血视角**：论文题通常**出题人自己也没指望很多人做出来** ⇒ 它对一血的意义在于：
> ① 别在它上面耗掉本该拿 3 个简单 flag 的时间；② 但**若你认出了论文**，它往往能一次性拿到一血（因为别人还在猜）。
> ⇒ **判据：认出论文线索 ⇒ 值得投 20-30 分钟；认不出 ⇒ 15 分钟止损**。

## 第 0·B 步：★论文题专章（怎么在 10 分钟内找到那篇论文）

> 素材来源均已实测验证（2026-10）：MetaCTF「Duality of Key」官方 WP、`CTF-Archives/2025-CCB-CISCN-Quals` 真实赛题库、
> `Towards Improving Intrusion Detection Systems Using Capture the Flag Events`（arXiv:2501.11685，**出题人自己写的出题方法论**）。

### 0·B.1 论文题的三种构造法（认出来了就知道该找什么）

| 构造法 | 特征 | 已知实例（可验证） |
|---|---|---|
| **抄骨架 + 改参数** | 题面/样本里能看到论文的影子，但**参数被动了手脚** | MetaCTF「Duality of Key」：题面直接写 *"The attack is based on techniques from **this paper**"*，并在 WP 里承认 **用了错的 φ 公式，是故意的** ⇒ flag 自嘲 `Th15_15_4_Pap3r_ch4113ng3_h4d_t0_tw3ak_1t` |
| **复现论文的某个方法** | 要你"实现论文里的算法"（而不是打一个现成漏洞） | 2025 CISCN 初赛 **AI 安全整类**：`欺诈猎手的后门陷阱`（XGBoost + .pth，**逆向后门触发规则**）、`The Silent Heist`（Isolation Forest 反欺诈） |
| **论文就是题目本体** | 题面给的"没有任何漏洞的界面"，考点就是绕过某个**检测模型/防御机制** | 同批 `AI_WAF \| 869`（AI WAF 防护绕过）—— 这类要你**对抗一个模型**，不是打一个组件 |

**共同点**：**常规手法（换 payload、扫目录、试 CVE）全部零收益**。别在那些动作上耗。

### 0·B.2 ★ 定位论文的检索式（实测可用）

**① arXiv 全文检索（最快，直接给 API）**

```bash
# 把题面里的核心名词塞进 all:"..."，AND 连接
curl -s 'https://export.arxiv.org/api/query?search_query=all:"web application firewall" AND all:"adversarial"&max_results=6'

# 实测结果：命中 WAF-A-MoLE / AdvSQLi / ModSec-AdvLearn 等直接对口的论文
```

**用法纪律**：
- 用**题面里最特别的那个词**（不是"防火墙"这种泛词，而是"对抗"、"后门"、"触发规则"这类方法词）
- 一次搜 2-3 组同义词（`adversarial` / `evasion` / `bypass`），取交集看哪篇同时谈到了你题目里的所有要素

**② 反向判据（省时间的）**

```
arXiv 全文检索【搜不到】 ⇒ 论文大概率在【顶会/期刊】（arXiv 只收预印本）
  实测例子：Isolation Forest 原始论文在 arXiv 搜不到 —— 它在 ICDM 2008
  ⇒ 换用：Google Scholar / dblp / 会议官网 proceedings 搜
```

**③ 从"没见过的算法/常量/魔数"反查**

```
论文自创的东西常留在样本里：变量名、常量表、魔数、结构体字段
⇒ 直接拿这些【字面量】去搜（含引号做精确匹配）
  例：一个 XGBoost 后门题，从模型文件里读出 4 个触发特征 → 搜 "XGBoost" AND "backdoor"
      → 命中 arXiv:2311.07550（该文明确说可泛化到 XGBoost/DeepFM）→ 4 个特征逐条对齐
```

### 0·B.3 论文 → 能跑的代码（三条落地路线）

| 论文给了什么 | 怎么落地 |
|---|---|
| **伪代码 / 算法步骤** | 照着写（论文的算法描述一般是给足细节的，照抄即可） |
| **公式 / 参数表** | **公式直译成代码**（Duality of Key 的解法就是把两个同余式相减 → 得到 `x - a ≡ 0 mod p` → 丢进 Coppersmith）|
| **有 artifact / 开源实现** | 直接找作者的复现库：顶会论文常挂 artifact（如 `secartifacts.github.io`）⇒ **先搜 "论文名 + github"** |

**跑不通时的排查顺序**：① 论文给的是**理论参数**，题目可能**缩小了规模**（先按题目的数跑）② 版本/依赖 ③ 论文的实验环境与题目环境不同（别硬套）。

### 0·B.4 「半成品得分点」——论文题的救命判据

**这条是实证的**（arXiv:2501.11685，出题人自述）：

> `teams earn points when submitting a flag, allowing them to gain credit even for intermediate results`

⇒ **论文题往往不是"全对才给分"**：
- 复现出**一部分**（拿到中间量、部分明文、部分 key）就可能对应一个 flag
- 完美解（如该论文的"零告警"）通常分值最高，但**中间结果也有分**

**行动**：卡在最后一步时，**先看看已经拿到的中间结果能不能拼出一个 flag 提交**，而不是死磕到底。

| `CTF-Archives/ctf-docker-template` | **一键起靶机环境模板** —— 赛前把常见环境跑起来练手，现场省时间 |
| `CTF-Archives` 各年度仓库 | `2025-CCB-CISCN-Quals` / `2026-WQB-Quals` 等，按年取 |

## 第 1 步：台账（这是给"上下文压缩后的自己"看的）

长赛事最大的隐性损耗是**重复劳动**。AI 会话会被压缩，人对 4 小时前的细节也会失真。每台目标维持一张表：

```
目标 | 已确认事实 | 已消除的假设 | 存活假设(按可能性排) | 下一步 | 卡点
```

- **"已消除的假设"是核心。**它防止你把同一个想法试第二遍——比赛里这几乎必然发生。
- 有新事实就落一行。**台账不再增长 = 卡死信号**（这就是换线判据，不看表）。
- 收口三行格式：`IP | 入口洞 | flag/权限 | 卡点 | 下一步`。

## 第 2 步：观察面榨干（难题的钥匙几乎总在"多看了一眼"）

逐项过，别跳。**每一项都要给出明确结论（有 / 无），"没看"不算过。**

**Web 面**

- **JS 全量**，不只是抽 `/api/`。盐、密钥、密文 id 的公钥、hidden/admin 路由、写死的演示账号、注释里的调试地址，全在 JS 里。`grep -rE "api|token|secret|key|admin|debug|password"`
- **报错页完整读**：栈里的内部路径、框架版本、组件名、内网 IP，每一个都是路标。没栈就换参数类型 / 加引号 / 发畸形包，主动逼出更深的栈
- **备份与泄露再扫一轮**：`.git .svn .DS_Store .swp`、`www.zip`、`网站名.zip`、`.rar`、`.tar.gz`、`.bak`、`/backup /old /test /dev`
- `robots.txt`、`sitemap.xml`、`/.well-known/`、`crossdomain.xml`——**被 disallow 的路径就是出题人藏东西的地方**
- 接口清单：Swagger `/swagger-ui.html` `/v2/api-docs`、Druid `/druid/`、`/actuator`、GraphQL——**专挑页面上没出现过的口**
- 响应头全集（自定义头、CORS 配置、CDN 特征）；HTTP 方法全试（OPTIONS / PUT / TRACE）
- **登录框：注册一个号进去再扫一遍。**很多面只在登录后暴露
- 静态资源的版本号 / 时间戳 / build id → 反推源码版本 → 对应 CVE

**主机 / 服务面**

- 全端口 `-p-` 重扫 + UDP `--top-ports 100`（前一轮扫漏是常态）
- 每个开着的服务都用浏览器 / `nc` 手工握一遍手，管理后台常在冷门端口
- 已有 shell 的：进程清单（`ps aux` 里常藏着第二个服务）、`crontab`、`history`、hosts、环境变量、第二张网卡、挂载点

**流量面**

- 抓包挂上：别人的攻击流量、服务间调用的内网请求，都是白送的情报（AWD 必做）

**应急面**（给的是机器 / 镜像 / 包 / 日志时）

- 先看**答题卡问什么**，问题清单决定排查方向——别漫无目的全盘扫
- 机器：进程树 → 网络连接 → 计划任务 / 启动项 / 服务 → 账户 → 日志 → 时间线
- 镜像：先用 `windows.info` 确认 profile 再按插件跑（见 `内存取证.md`）
- 流量：协议分层 → 会话排行 → 外连 → 导出对象（见 `应急-流量与隧道.md`）

## 第 3 步：组合矩阵（低危串高危）

把**已拿到的所有东西**列成清单（哪怕看着没用），逐对问"**这两个能连吗**"。难题通常 2–3 个低危串成一条。

| 已有 | 常见下一环 |
|---|---|
| 任意用户 / 弱口令进后台 | 后台功能挖上传 / SSRF / 模板编辑 / 定时任务（低权后台 ≠ 安全） |
| 任意文件读 | 读配置拿数据库凭据 → 读源码找 0day → 读 history / 私钥拿 SSH |
| debug 页 / 配置泄露 | 抠 SECRET_KEY、API token、数据库口令 → 直通后台或签发合法 token |
| SSRF | 打内网 Redis / FastAPI / 云元数据 → 二次放大 |
| 源码泄露 | 审计找注入 / 反序列化 / 硬编码钥匙 |
| XSS | 打管理员 cookie → 进管理面 → 上传 |
| 数据库账号 | UDF / `writefile` 写马；同凭据试 SSH / 后台 |
| 一台低权 shell | 抓凭据 → 全段复用 → 提权 → 域内横向 |
| LFI | 包含日志 / session / `pearcmd` 落马 |
| 一个密文 id / 公钥 | 自己加密相邻 id 换进去；或对着演示号换邻号 |
| 一个签名 header | 找签名算法（JS / 报错 / 文档），现签其它接口 |

**组合的通用律**：每拿到一个新东西，**回到本表重跑一遍**。链只想到一层，是难题最常见的死因。

更细的升级路径字典见 `web/escalation-handbook.md`。

## 第 4 步：冷门面（主流洞全没 = 出题人用了冷门洞）

指纹认得出但主流洞全打不通，恰恰说明考点在冷门处。按命中率开 `web/` 子库：

- `prototype-pollution-test.md`（原型污染 → 模板 RCE）、`type-juggling-test.md`（PHP 类型杂耍登录绕过）
- `cache-poisoning-test.md`、`http-smuggling-test.md`（前后端分离 / 代理架构）
- `race-condition-test.md`（支付 / 兑换 / 限领）
- `ghost-bits-cast-test.md`（隐形字符）、`el-injection-test.md`、`websocket-test.md`
- 解析层差异：URL 编码、HPP、路径归一化（401/403 绕过的现场姿势）

主机侧冷门面：容器逃逸（docker 组 / `docker.sock` / privileged + `nsenter`）、NFS `no_root_squash`、capabilities、`ld.so.preload` 劫持。

## 第 5 步：反转假设（题目是出题人设计的，就按出题人想）

打不动时切一次视角，问：**"如果这题就是要卡住我，出题人会怎么设计？"**

- 会藏在**你默认不看的位置**：默认不扫的端口、默认不看的头、默认不信的参数、默认跳过的备份文件
- 会设**看起来正常的假象**：正常版本号（镜像回过炉）、正常 200（其实载荷没进去）、正常页面（其实有参数）
- 会考**一个工具的边界**：工具默认姿势不通，但换个参数 / 版本 / 链就通
- 会放**跨协议 / 跨层的连接**：DNS 出数据、ICMP 带外、序列化跨服务

配套动作：把"我默认没做的假设"列出来，逐个反着试一遍。

## 第 6 步：假点 —— 别把"通了"判成"不通"

**这是最容易丢分的环节。**多数"此路不通"其实是判据错，不是洞不对：

| 现象 | 真相 |
|---|---|
| 靶机返回 500 + 一串数字 | 命令执行成功了但退出码非零（如 execSync 抛异常）。**命令链加 `; true` 收尾再打** |
| Shiro 爆出 key、链全炸 | key 是对的，依赖对不上，**换链不停**（CB 链不依赖 CC，优先试） |
| fscan 报的洞全炸 | 不代表机器没洞，手工接着打；报错也可能只是 POC 与版本不匹配 |
| 内网图加载失败 / 无回显 | 出网被限。**先判通（dnslog / 延时 / 带外）再上工具**，或改正向 bind |
| access.log 里找不到马的路径 | 内存马的路径可以和日志无关，回头全量 dump FilterMap |
| pslist 看着干净 | 上 pstree 看父子关系 + psscan 扫已退出进程 |
| Windows 事件日志被清 | 看 Prefetch + USN journal + 文件系统时间线，痕迹清不完 |
| 日志里 IP 很多 | 以**请求特征**判凶手（高频 POST、异常 UA、成功登录的爆破源），不是数谁请求多 |
| 时间对不上 | UTC 与本地差 8 小时，时区是经典坑 |

**通用动作**：判"不通"之前，先问一句"**我是怎么判定它不通的？这个判据可靠吗？**"

---

## 第 7 步：无解止损与收口

- 先把简单中等全部收掉，难题挂着后台想。**难题是胜利的条件之一，不是必要条件。**
- 卡住时后台任务（爆破 / 扫描 / sqlmap）**不要杀**，挂着继续跑，人换线——这样换线几乎零代价。
- 终场前把台账里"找到了但没报告"的全部汇总报告出来（提交由人工做），格式再对一遍。
- 打穿后回填知识库，四要素（认 / 打 / 算成 / 假点）落进对应文件。

## AI 协作姿势（难题阶段的正确用法）

速度题：让 AI 出 payload，你执行。

难题：把**全部已知信息**（指纹、所有响应原文、报错栈、JS 摘要、已试过什么、台账）**一次性**交给 AI，让它做交叉联想出**假设清单**，你逐个验证带回结果，循环收窄。

不要挤牙膏式地问"这站怎么打"——信息给得越全，联想质量越高。同理，把自己手上那台机器的**全部观察结果**先摆上桌，再开始连。
